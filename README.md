## 📖 About

Nether Fortress Finder predicts fortress bounding boxes from the world seed, highlighting corridors and blaze spawner rooms through Netherrack.

---

## ✨ Features
<a name="features"></a>

- **Fortress Bounding Box** — full structure outline rendered in the Nether.
- **Blaze Spawner Rooms** — specific rooms highlighted.
- **Wither Skull Loot** — marks wither skeleton zones.
- **Distance Sort** — nearest fortress listed first.
- **Map Markers** — pinned on minimap.
- **Toggle Key** — quick on/off.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
